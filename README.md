📋 Overview
-----------

AutoDarts + is a browser extension that enhances your experience on [autodarts.com](https://autodarts.com). It adds quality-of-life features, customization options, and advanced functionality to make your Autodarts experience more enjoyable and personalized.

✨ Features
----------

### 🎨 Match Customization

*   **Darts Customization**: Design your own unique darts or import custom SVG code

### 🎮 Gameplay Features

*   **Local tournaments**: Create your own local tournaments with KO, league or groups
*   **Ranked**: Play a ranked mode with bronze, silver, gold, platinum, diamond, champion and world master rank

### ⌨️ Shortcuts

AutoDarts + allows you to configure your own keyboard shortcuts for frequently used actions.

*   **Board Calibration**: Assign a custom key to quickly calibrate your board
*   **Next Player**: Assign a custom key to switch to the next player
*   **Last Player**: Assign a custom key to switch back to the previous player

All shortcuts can be customized to match your preferred setup.

⚙️ Configuration
----------------

The extension provides a comprehensive settings panel where you can configure all features according to your preferences:

*   Enable/disable individual features
*   Customize colors and appearance
*   Set timing for automatic actions
*   Configure Discord webhook integration
*   Adjust sound settings and upload custom sounds
*   Customize streaming mode settings
*   Configure keyboard shortcuts for supported actions

### 📤 Settings Import/Export

The extension allows you to easily transfer your settings between devices or create backups:

*   **Export Settings**: Download your settings as a file
*   **Import Settings**: Load your settings from a previously exported file
*   **Copy to Clipboard**: Copy your settings for easy sharing
*   **Paste from Clipboard**: Apply settings that were copied from another installation
*   **Reset Settings**: Restore your settings to their default values through the Danger Zone section

This makes it simple to:

*   Back up your perfect configuration
*   Share your setup with friends
*   Transfer your setup between browsers and devices
*   Restore your settings after reinstalling the extension
*   Start fresh with default settings

👨‍💻 Development
-----------------

This project is built using:

*   Javascript
*   Vite

### 🚀 Getting Started

    # Install dependencies
    yarn install
    
    # Start development server
    yarn dev
    
    # Build for Chrome and Firefox
    yarn build
    
    # Build for Firefox
    yarn build:firefox

    # Build for Chrome
    yarn build:chrome
